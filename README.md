One sentence, 128 characters, on the best advice I ever received — my grandmother's lesson that kindness is a habit, not a feeling.

## Entry

> My grandmother kept a spare key under the mat for the neighbour she never liked, and told me kindness is a habit, not a feeling.

## How it works

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt` into the output directory the grader provides. No rendering happens at grade time, so the output is byte-identical on every run.
